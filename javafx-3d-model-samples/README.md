# javafx3d-samples

---

A collection of minimal hzt.sample code for JavaFX 3D

---

## LoadModelApp

The required jars are added as local-mvn-repo in [local-mvn-repo](local-mvn-repo). It is referred to in the pom.

The structure in the local repo can be obtained by running [install-3d-model-jars-to-mvn.cmd](lib/install-3d-model-jars-to-mvn.cmd)
